# BNC Apparel website

Static lead generation site with a WebGL fabric hero, smooth scroll, parallax and a horizontal lookbook, for www.bncapparel.site. No build step. Upload `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml` to any host (Netlify, Vercel, GitHub Pages, Hostinger).

## Before going live
1. Create a free form at https://formspree.io and paste the endpoint into `FORM_ENDPOINT` at the top of `script.js`.
2. Set `CONTACT_EMAIL` in the same file.

Each audit request arrives with a subject like `[HOT] Free audit request: BrandName`, scored from stage, budget, platform and social presence, so the best leads stand out.

## Lookbook
The "Concept drops" in the Work section are example projects. Replace them with real client work (brand, what you fixed, result) as soon as you have it.

Libraries (Three.js, GSAP, Lenis) load from cdnjs and jsDelivr. If they fail, the page still works and the hero falls back to a gradient.
