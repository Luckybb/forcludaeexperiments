# BNC Apparel website

Static lead generation site with a WebGL fabric hero, smooth scroll, parallax and a horizontal lookbook, for www.bncapparel.site. No build step. Upload `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml` to any host (Netlify, Vercel, GitHub Pages, Hostinger).

## Before going live
1. Put your booking link (Calendly, WhatsApp, etc) in `BOOKING_URL` at the top of `script.js`, and set `CONTACT_EMAIL`.
2. Add portfolio images to `images/work/` (see the README there).
3. A contact form can go where the `<!-- Contact form goes here -->` comment sits in the audit section.
