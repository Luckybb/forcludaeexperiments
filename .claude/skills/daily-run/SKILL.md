# Daily run (bottleneck first)

The bottleneck is turning replies into qualified, booked calls, not lead volume. Work in this order and finish each step before the next.

1. **Read** LEADS.md, PLAYBOOK.md, and today's section of MESSAGES.md. Check Gmail sent items from the last 24 hours, so you know what the other session already did.
2. **warm-reply**: every new reply and booking. Upcoming calls without brand info get the details email. Then a call reminder on the morning of the call.
3. **follow-ups**: everything due, oldest first, up to 50.
4. **Lead supply check**: if fewer than 20 enriched leads are waiting with verdict email, scrape new US, Canada, UK and Europe apparel brands, then run enrich-leads.
5. **cold-outreach**: new enriched leads, up to the daily cap (total new + follow ups at or under 50 unless Ben says otherwise).
6. **Update PLAYBOOK.md**: reply counts per angle and nugget type.
7. **sync-doc** for both files. Commit and push.
8. Send Ben one short summary:
   - replies and bookings
   - calls coming up
   - sends made
   - anything that needs his judgment

   Nothing else.

Never send twice to the same lead on the same day. When unsure if the other session sent something, check Gmail, don't guess.
